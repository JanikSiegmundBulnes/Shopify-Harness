## Sandbox- und Permission-Konzept (`template/.claude/settings.json`)

| Aktion                                                                                   | Stufe                         | Durchgesetzt durch                                       |
| ---------------------------------------------------------------------------------------- | ----------------------------- | -------------------------------------------------------- |
| Code in `src/` ändern, eigene Tools, `npm test`/`typecheck`/`build`, `git status`/`diff` | erlaubt                       | `allow`                                                  |
| Akzeptanztests, `vite.config.ts`, `tsconfig*.json`, `package.json` ändern                | verboten                      | `deny`                                                   |
| `AGENTS.md`, `CLAUDE.md`, `.claude/`, `.mcp.json` ändern                                 | verboten                      | `deny`                                                   |
| `.skip`/`.only`/`.todo`, `@ts-ignore` einfügen                                           | verboten                      | Hook `protect-checks.mjs` (Exit 2)                       |
| `.env` lesen                                                                             | verboten                      | `deny` + Hook                                            |
| `git commit`, `git push`                                                                 | verboten                      | `deny`                                                   |
| sonstige Shell-Befehle                                                                   | Nachfrage, headless abgelehnt | nicht gelistet                                           |
| Netzwerk, Schreiben außerhalb des Projekts                                               | blockiert/Nachfrage           | Sandbox (`failIfUnavailable`, keine unsandboxed Befehle) |

**Tests:**

- Sandbox: `curl https://example.com` → Freigabe verlangt, abgelehnt.
- Hook: „Füge in src/lib/cart.test.ts ein it.skip ein“ → blockiert, Datei unverändert.
- `run_typecheck` ohne Modell: grüner Fall `ok: true`; roter Fall (`const x: number = "a"`) meldet TS2322 mit Datei und Zeile.

**Grenzen:** MCP-Server, Datei-Tools und Hooks laufen außerhalb der Sandbox. Der Hook erkennt nur bekannte Schreibweisen. `acceptEdits` erlaubt headless alle Änderungen, die keine `deny`-Regel trifft.
